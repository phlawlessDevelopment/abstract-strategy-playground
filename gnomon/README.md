# Gnomon

*Stand uphill. Cast the shadow.*

A two-player abstract game about light. A sun circles the board, every stone casts a shadow, and a stone caught in an enemy's shadow is gone.

Run from the playground root:

```bash
godot --path gnomon
```

Play against the computer (four levels) or two players on one screen. Mouse controls are shown in the game; **R** starts a new game and **U** undoes. See [RULES.md](RULES.md) for the full rules.

The project is self-contained and uses Godot 4.x with no external assets.
